# AGENTS

## COMMIT MESSAGES

* Always add new words to cspell, sorted and each on a new line.
* Always classify README.md or .assets/ changes as the docs type.
* Always keep every commit subject short, concise and easy to scan.
* Always omit the scope when the repository is not a monorepo.
* Always start every commit subject with a clear indicative verb.
* Always use the `and` word before the final item in all enumerations.
* Never add `co-authored-by` trailers from any ai tool or agent.
